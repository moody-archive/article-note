# 기사 프로젝트 노트

기사 프로젝트를 정리하는 한 장짜리 노트 페이지야. HTML 파일 하나로 되어 있어서 설치 없이 브라우저로 열면 바로 쓸 수 있어.

## 구성

| 칸 | 설명 |
| --- | --- |
| 프로젝트 한 줄 | 프로젝트 브리프를 한 줄로 적는 칸 |
| 주제 | 대주제: **경제** |
| 할 일 체크리스트 | 할 일 5개. 체크하면 취소선이 그어짐 |
| 날짜별 기록 | 11/18부터 시작. 날짜마다 오늘 한 줄을 기록 |

## 특징

- 검정 배경에 흰 글씨로 된 깔끔한 디자인
- 휴대폰 화면에 맞춰 자동으로 레이아웃이 조정됨
- 외부 라이브러리 없이 HTML 파일 하나로 동작
- 전화번호, 주소 같은 개인정보 칸은 없음

## 사용법

1. `article-project-note.html` 파일을 브라우저로 열어.
2. 각 칸을 눌러서 내용을 적어.
3. 다른 날짜에 열었을 때 **+ 오늘 기록 추가** 버튼을 누르면 그날 날짜로 기록 줄이 추가돼.

## 저장 방식

적은 내용은 브라우저의 `localStorage`에 자동 저장돼.

- 같은 기기, 같은 브라우저로 다시 열면 내용이 남아 있어.
- 다른 기기나 다른 브라우저에서는 보이지 않아.
- 브라우저 데이터를 지우면 저장한 내용도 같이 지워져.

## 파일 구조

```
.
├── article-project-note.html   # 노트 페이지

```
